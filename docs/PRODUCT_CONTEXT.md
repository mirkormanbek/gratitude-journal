# Product context

## What this product is
Growth OS is a private personal operating system. The original project was “Дневник роста” and contained a daily journal, CEO Review, knowledge base and capital tracking. It later gained AI, Quran reading, Person of the Day, task/project management and workouts.

The central product idea is now broader than a journal: one extensible system for planning, reflection, learning, faith, health, discipline and progress.

## User intent
The user wants a practical system that reduces mental overhead. The application should make it obvious:
- what matters today;
- what is planned next;
- what larger project each action advances;
- how consistency/progress changes over time;
- where reflection belongs;
- how new services can be added without breaking navigation.

The user dislikes UI that becomes long, repetitive or patched together as features accumulate.

## Product principles established in conversation
- Build an operating system, not a collection of unrelated pages.
- Keep only the most important 5 primary navigation destinations.
- Put new modules into Services and integrate them into shared Today/Plan/Progress surfaces.
- One calendar layer should eventually coordinate tasks, workouts, habits/events etc.; do not create independent calendars for every module.
- Dashboard cards should summarize and open detail views, rather than dumping full content on Today.
- A feature is not successful just because it technically works; daily usability on iPhone is the standard.
